# Imported Asset Sources

## SuperBomberman2Items.png

- Game: Super Bomberman 2 (SNES).
- Sheet: Items, uploaded by Superjustinbros to The Spriters Resource.
- Source: https://www.spriters-resource.com/snes/sbomber2/asset/87958/
- Downloaded: 2026-10-04, unchanged original 128 by 96 PNG.
- Used frames: Bomb Up at (0, 0), Fire Up at (16, 0); both 16 by 16 pixels.
- Rendered at 32 by 32 pixels inside the existing 50-pixel game tiles.
- The archive upload is a source reference, not an independent asset license.

## BombermanNESEnemies.png

- Game: Bomberman (NES, 1985).
- Sheet: General Sprites, The Spriters Resource.
- Source: https://www.spriters-resource.com/nes/bomberman/asset/7884/
- Downloaded: 2026-10-04, unchanged original 224 by 383 PNG.
- New enemy rows: Onil 255, Dahl 271, Minvo 287, Kondoria 303,
  Ovapi 319, Pass 335, Pontan 351. Frames are 16 by 16 pixels.
- Walking frames start at x=0 with 16-pixel spacing; death uses each
  species' hit pose and the matching shared shrinking frames.
- The renderer removes the sheet's two green background colors once in
  a cached canvas. The source file remains unchanged.
- The existing balloon walking and death art is preserved.
- Species behavior and scores use the NES reference table:
  https://strategywiki.org/wiki/Bomberman/Gameplay
- Speeds, pursuit algorithms, enemy counts, and level composition are
  adaptations for this project, not an exact recreation of NES code.
- The archive upload is a source reference, not an independent asset license.
